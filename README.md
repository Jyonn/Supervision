# Supervision / 板凳：科研记录与研究组协作

## 当前开发版本：Frienden 普通账户接入（2026-10-24）

本次开发版本已移除 Frienden OAuth 登录、回调、授权与委托聊天接口。使用 Supervision 自己的邮箱账号登录；Frienden 账户仅在研究组内连接，不负责登录或创建 Supervision 账号。

- 导师创建研究组时提供空间 slug、官方账户昵称和密码。后端通过 `/users/me` 的 `official` 与 `/spaces/me` 的 `official_user.user_id` 双重核验官方身份。
- 学生先登录 Supervision，再通过邀请提供对应空间的个人账户昵称和密码。空间由邀请固定，不能选择其他空间或借用官方账户。
- 使用 `/spaces/join` 的 `new_user_intent=check` 模式，只连接已有账户；密码不保存，access/refresh token 只在服务器私有 vault 加密保存并刷新。
- 聊天采用与当前工作区一致的暖色、列表和细分隔线，无消息气泡。支持本组已有会话、组员私聊、文字发送、历史分页、近期记录轮询与手动同步。群会话须已在 Frienden 建立，且当前参与者均属于本研究组；空间全员群和投稿会话不展示。
- 原 OAuth 凭据不会转换成普通账户凭据。现有账号、任务和研究组数据保留；成员需要重新连接对应空间账户。旧 OAuth 专属 Supervision 账号如果没有可用的邮箱/密码，需先解决 Supervision 本身的登录，系统不会按昵称自动合并身份。
- 不包含好友申请、群管理、建群、媒体上传或自动发送科研记录。头像中既有 Frienden 缓存属于历史资料，不会触发 OAuth。

本版本已通过隔离验证；实际发布状态见交付记录。验证未使用真实用户的 Frienden 账号。运行与历史交付记录见 [ACCOUNT.md](ACCOUNT.md)；普通账户协议与验证说明见 [CHAT-LOCAL.md](CHAT-LOCAL.md)。

```sh
npm run start:accounts
npm test
npm run test:accounts
```

# 演示原型说明

无需安装依赖。运行 `npm start`，打开 http://127.0.0.1:4173 。也可直接打开 index.html（浏览器本地存储策略可能不同）。预览仅绑定本机，不部署。

## 审阅路径

1. 概览：首页显示本周任务、每日待更新、最新进展、待导师回应问题与下次会议。
2. 点击任务：任务说明 → 本人每日进展 → 总结与反馈。
3. 编辑今日进展：进入统一编辑器，选择编辑 / 对照 / 预览模式，使用框内分组图标工具栏插入表格、代码、行内 / 块公式与模拟图片，保存后保留在本浏览器。
4. 总结与反馈：学生编辑个人总结；顶部切换虚构导师，分别查看林澄与周予，并填写个人反馈。
5. 会议：查看静态忙闲模拟，编辑会议纪要。
6. 研究组：查看成员与功能边界，调整学生互看假设。
7. 手机宽度：先看列表，点任务进入详情，再通过“本周任务”返回。编辑使用整页布局。

## 真实与模拟

- 真实：导航、任务选择、Markdown 编辑与预览、浏览器本地保存、独立个人记录、总结、导师反馈、会议纪要、响应式布局、焦点样式、标签页方向键。
- 模拟：身份和隐私权限、两人任务分配、七牛云图片上传、Chronelle 忙闲。没有账号、密钥、真实日程、后端或生产数据库。
- 所有人物、研究组和实验数据均为虚构。日报日期固定在示例周；历史日报为静态示例，今日编辑覆盖当天内容。
- Markdown 原型子集：标题、无序列表、粗体、引用、表格、代码块、行内代码、HTTP(S) 链接与图片。公式以公式文本展示，不是完整 LaTeX 排版；尚未集成 Milkdown / KaTeX，也不宣称 CommonMark 全量兼容。
- 最新进展与待回应提示是静态首页样例；不会根据编辑自动汇总。模拟上传插入仓库内 sample.svg；不会真正上传。
- 不应在此原型输入真实敏感科研信息。权限开关只改变展示，不提供安全隔离。

## 验证

`npm test`：语法检查与 VM 交互检查，涵盖默认学生可见性、成员内容独立保存、总结与导师反馈、纪要、导航和 Markdown 转义。

已在原生 Chrome 打开并读取真实页面；桌面首页和 iPhone 16（393 × 852）首页已通过工具截图查看，未见导航或控件重叠。手机点击任务后，可访问树显示详情及返回按钮。已导出真实页面 PNG：screenshots/home-desktop.png、home-mobile.png、editor-desktop.png、editor-mobile.png；截图不包含浏览器其他标签内容。自动化浏览器扩展连接失败，原生浏览器操作也曾因用户同时切换页面而中止；没有完成全部交互的浏览器端回归或完整视觉验收。

## 设计取向

适合 Web 的 Apple/HIG 风格：系统字体、实色顶部、轻边框、紧凑控件、稳定侧栏与列表详情、语义按钮、可见键盘焦点与减少动画；不声称原生 Apple 应用。

## 编辑器修订

格式工具栏已移入统一边框，使用紧凑分组图标与 title / aria-label。支持选区加粗、撤销 / 重做、⌘/Ctrl+S 保存、⌘/Ctrl+B 加粗、⌘/Ctrl+Z 撤销。编辑、对照、预览共享 draft；返回、导航和切换视角会保留本地草稿，重新进入对应任务可恢复。

角色检查：只有林澄（学生）与陈知远（导师）两个选择项，无 disabled 选项。周予为可查看的虚构成员，没有独立学生登录视角；默认隐藏他人日报符合已标注的隐私假设。

## 最新修订：页面分工与一步表格

概览已独立为待办、最新进展和下次会议摘要；任务页提供搜索与状态筛选，不再复用概览主体。已删除首页重复副标题与编辑器重复技术说明，限制集中于研究组说明。

表格按钮使用锚定 6×6 浮动矩阵，hover / focus 高亮选区，点选直接插入，无数字表单或额外确认。支持方向键、Enter / Space、Escape 与外点关闭；保留原光标 / 选区。表格底层仍是 Markdown 源文。

手机工具栏保持一条横向可滚动格式栏，模式栏固定另占一行；返回 / 保存保持单行。已用 responsive-review.html 的 320px 与 393px iframe 视口并排检查；页面与编辑器无控件重叠。最新浏览器验证和截图在工具记录中，screenshots/ 及此前 Library PNG 是上一版，不能当作本次页面分工和方格选择器修订截图。
